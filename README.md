# 3×4将棋 完全解析ボード

3×4マスのミニ将棋を、全局面の完全解析データで検討できる Web ページです。
どの手を指せば何手で勝ち・負けになるかを、候補手ごとに日本語で表示します。

- 検討：駒を選ぶと動かせるマスに評価、候補手は良い順に並びます。候補手にカーソルを乗せると盤に矢印が出ます
- 棋譜：悪手（勝ちを逃した・負けを早めた手）に自動で印が付きます
- 局面編集・AI対戦（強さ3段階）・URLで棋譜を共有

ルールは北尾まどか氏が考案した「どうぶつしょうぎ」と同じです。本ツールは非公式で、考案者・販売元とは関係ありません。

## 解析

初期局面から到達できる 246,803,167 局面（左右反転をまとめた数）すべてについて、勝ち・負け・引き分けと決着までの手数を後退解析で求めました。
初期局面は後手の勝ち（78手）で、田中哲朗「『どうぶつしょうぎ』の完全解析」（2009）の結果と一致します。

作り方は [BUILD.md](BUILD.md) を参照してください。

## 構成

- `solver/` 解析（C）と Web 用データの作成
- `web/` 公開するページ（HTML/JS、ビルド不要）。`web/data/` が解析データ（約78MB）
